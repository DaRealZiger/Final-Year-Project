#slide("1.0 Introduction")[
  *1.1 Project Background*
  - Certificates are widely used for recognition, participation, and completion
  - Manual preparation involves design, data entry, and document production
  - Existing tools require combining multiple applications for design, data, and generation
  - *Proposed solution:* A web-based certificate generator using Flutter Web
    - Layered certificate design + template reuse
    - Manual entry and CSV import for recipient data
    - Batch generation into a single PDF
    - User accounts for persistent storage
]

#slide("1.2 Problem Statement")[
  - *Repetitive manual effort:* Each certificate is edited individually → errors in names, dates, and positioning
  - *Poor reuse and management:* Templates and recipient records scattered across files/apps
  - *Scaling issues:* Large groups need reliable data-to-field association
  - *Need:* Centralized, automated system with consistent PDF output
]

#slide("1.3 Project Objectives")[
  + Develop a *web-based certificate generator* with layered design elements and reusable templates
  + Implement a *centralized management system* for templates and recipient data via user accounts
  + Develop *individual and batch generation* supporting manual entry and CSV imports → consistent PDF output
]

#slide("3.1.1 SDLC Phases")[
  + *Planning & Requirements Analysis*

  + *Prototype Design & Construction*
    - Test text positioning, layered elements, CSV imports, PDF generation
  + *Prototype Evaluation*
    - Identify technical issues; refine final design
  + *Final System Design & Implementation*
    - Build with Flutter Web + self-hosted backend
    - Discard prototypes; apply lessons learned

#slide("3.1 Principal of Operation")[
  - Users log in to access saved templates and recipient data
  - *Design:* Create from scratch with layered elements or upload existing background
  - *Customize:* Position and format text elements (names, titles, dates)
  - *Save:* Store templates for future use
  - *Data:* Manual entry or CSV import
  - *Generate:* Apply data to template → individual or batch
  - *Output:* Combined PDF for review, printing, and distribution
]

#slide("3.1.3 Use Case Specification (Summary)")[
  *UC01: User Login*
  - Actor: Student / User
  - Precondition: Registered account
  - Flow: Open app → enter credentials → validate → authenticate → dashboard
  - Postcondition: Access to saved templates and recipient data

  *UC: CSV Import*
  - Actor: Student / User
  - Precondition: Logged in; CSV file available
  - Flow: Upload → read headers → map fields → validate → preview → confirm → save
  - Postcondition: Valid records imported for generation
]

#slide("3.1.3 Use Case Specification (Cont.)")[
  *UC: Generate Individual Certificate*
  - Select template → select/enter recipient → validate → insert details → preview → export PDF

  *UC: Generate Batch Certificates*
  - Select template → select dataset/CSV → validate → preview → confirm → apply to each record → combine into one PDF → export

  *UC: Export / Print PDF*
  - Review pages → select pages (if supported) → export or print

  *UC: Admin Account Management*
  - Search/select account → view info → deactivate/delete → confirm → apply change
]
